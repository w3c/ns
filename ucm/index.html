Status of this document

This vocabulary is an incubation being developed by the Unified Care Model (UCM) Community Group at the W3C. It is an early draft (v0.0.1) and is subject to change as the Community Group refines it through use-case-driven, consensus-based development. Comments and issues should be directed to the public-ucm mailing list. The UCM builds upon W3C Semantic Web standards (RDF, RDFS, OWL, SHACL) and adopts the Simple Upper-Level Ontology (SULO) as its foundational upper ontology.

Namespace URI

The namespace URI for UCM is https://www.w3.org/ns/ucm#.

Alternative serialisations

The vocabulary is published both in human- and machine-readable forms. A GET request made to the canonical namespace URI will cause HTTP Content Negotiation to occur, which means that the most appropriate variant will be served according to your request. However, if you explicitly wish to retrieve a particular serialisation, you can also do so using the following URLs:
